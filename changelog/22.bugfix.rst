`~plasmapy.diagnostics.pic_thomson.spectra_from_phase_spaces` takes
``n_quadrature_points``, which sets how finely the forward model samples the
principal-value integral for :math:`\chi`. The default is unchanged, and is
enough for a smooth distribution: on an analytic Maxwellian the default
reproduces the converged spectrum to 0.02 dex at :math:`\alpha \approx 4`.

It is not enough for a PIC histogram. `~plasmapy.diagnostics.thomson.arbitrary_chi`
evaluates :math:`\int f'(u)/(u - \xi)\,\mathrm{d}u` on a sample grid anchored at
:math:`\xi` and geometrically graded away from it, so as :math:`\xi` sweeps the
wavelength axis the grid slides underneath a shot-noise-roughened :math:`f'`
and the quadrature error oscillates with it. The result is a regular ringing in
the computed spectrum whose period is set by the outer sample spacing -- about
2.2 nm on a KinShock run at 532 nm -- and which is uncorrelated frame to frame
because the noise it is sampling is.

On ``KinShock2020/runs/R1_phase/R1_paper_470eV`` at z = 0.69 mm the wings of
both features carried 0.56 dex (EPW) and 0.64 dex (IAW) of this ringing after
the shock passed the probe. Raising ``n_quadrature_points`` to ``1e4`` -- which
is converged, and agrees with ``1e5`` -- takes them to 0.10 and 0.045 dex. The
ion-feature FWHM moves by up to 14% between the two, so IAW widths measured at
the default carry that as a systematic.
